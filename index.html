Sample GitHub repos for builds
Fork each into your own GitHub account so you can add a Jenkinsfile and push changes. Install a JDK and Maven on the Jenkins machine, or configure Maven under Manage Jenkins, Tools.
  • simple-java-maven-app: Java, Maven, JUnit. Main repo for Days 2, 3 and the capstone.
  • simple-node-js-react-npm-app: Node and npm. Needs Node.js on the machine.
  • simple-python-pyinstaller-app: Python. Needs Python and PyInstaller.
  • spring-petclinic: larger Java app for stretch work.
